# 系统架构规划

本文档根据需求整理 Web/App 端技术选型、后端栈、基础设施与数据模型规划，为后续研发与部署提供统一基线。

## 前端
- **Web 端**：Next.js + React（或 Vue/Nuxt，保持同构渲染能力与 SEO 友好）。
- **App 端**：React Native（或 Flutter），与 Web 端共享业务逻辑与设计体系，优先支持 Code Push/OTA 更新。
- **静态资源**：统一走 CDN 加速，入口由反向代理（Nginx/Caddy）负责路由与压缩。

## 后端与接口
- **运行时**：Node.js（NestJS 优先，Express 作为轻量备选）或 Go。
- **接口协议**：REST/GraphQL 任选其一或同时暴露，GraphQL 建议启用 schema 版本管理与持久化查询。
- **数据库**：PostgreSQL（优先）或 MySQL，使用 Prisma/TypeORM（Node）或 GORM/Ent（Go）进行模型管理与迁移。
- **对象存储**：S3 兼容存储用于图片/文件；开启生命周期与访问策略（私有 + 签名 URL）。
- **缓存与队列**：Redis（会话、限流、队列），可选 Kafka/RabbitMQ 处理生成任务。

## 基础设施
- **反向代理与安全**：Nginx 或 Caddy 统一入口，启用 HTTPS（Let’s Encrypt/ACME），WAF/限流/日志汇总。
- **CDN**：静态资源与图片走 CDN；生成类资源可通过缓存键与版本号控制更新。
- **环境分层**：开发/测试/生产三套环境，隔离凭据与数据；测试/生产启用只读与速率限制策略。
- **容器化**：Dockerfile + docker-compose 本地编排；生产使用 K8s 或容器服务（含健康检查、自动扩缩容）。
- **CI/CD**：流水线包含 Lint/Test/Build/镜像推送/部署；提供蓝绿或金丝雀发布流程。

## 数据模型（ER 基线）
- **用户 User**：账户、角色、订阅状态、余额。
- **作品 Work**：所属用户、封面、标签、公开状态。
- **章节 Chapter**：隶属作品，标题/排序/付费配置。
- **页面 Page**：隶属章节，图片路径、文本、AI 元数据、排版信息。
- **付费订单 Order**：用户、支付渠道、金额、状态、关联作品/章节。
- **公告 Notice**：标题、内容、生效时间、受众。
- **推荐位 Slot**：曝光排序、权重、关联作品/章节。
- **阅读记录 ReadingLog**：用户、作品/章节/页、阅读进度、最后访问时间、设备指纹。

## 部署与运维要点
- **日志与监控**：集中日志（ELK/Datadog），指标（Prometheus + Grafana），链路追踪（OpenTelemetry）。
- **备份与灾备**：数据库与对象存储定期备份，异地冗余；预置恢复演练。
- **权限与审计**：细粒度 RBAC，审计关键操作与管理入口；对接 SSO/OIDC 可选。
- **成本优化**：冷热数据分层存储，图片压缩与 WebP/AVIF，自适应限流。
